# Python Fundamentals Practice

A collection of beginner-friendly Python projects and exercises focused on building a strong programming foundation for Data Analytics. This repository covers core Python concepts such as functions, conditional statements, loops, lists, dictionaries, tuples, error handling, and menu-driven applications.

## Projects Included

* Loan Eligibility System
* Student Score Management System
* Employee Management System (in progress)

The goal of this repository is to practice problem-solving, write clean Python code, and build the foundational skills needed for data analysis, automation, and ETL workflows.
